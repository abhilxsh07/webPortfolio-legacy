# webPortfolio-legacy

My first portfolio site, built between November 2025 and February 2026 while I was learning React. It has been replaced by [abhilashkar.dev](https://abhilashkar.dev/) ([source](https://github.com/abhilxsh07/portfolio_v2)), and this repo is archived.

**Live:** [abhilxsh07.github.io/webPortfolio-legacy](https://abhilxsh07.github.io/webPortfolio-legacy/)

## What's in it

- A profile card, typed and rotating headline text, a projects grid and a contact section.
- WebGL backgrounds (Iridescence, Aurora, Color Bends) rendered with OGL and three.js, with GSAP and Motion for animation.
- Most of the animated components come from [React Bits](https://reactbits.dev), adapted for this site.

**Stack:** React 19 · Vite 7 · OGL · three.js · GSAP · Motion · CSS

## Run it locally

```bash
npm install
npm run dev
```

`npm run build` writes the site to `docs/`, which GitHub Pages serves.
